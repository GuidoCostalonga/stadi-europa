# Stadi d'Europa

Mappa interattiva di 490 stadi della prima e della seconda divisione dei 15 principali campionati europei, stagione 2026-2027.

Pagina online: https://guidocostalonga.github.io/stadi-europa/

Singolo file HTML autonomo (`index.html`): Leaflet 1.9.4 + MarkerCluster 1.5.3 inclusi, nessuna build necessaria.

Interfaccia e schede sono in italiano. Il testo della sezione "Da Wikipedia" viene caricato al volo:
la scheda cerca prima la voce italiana (anche quando il dato di partenza è la pagina inglese) e
ripiega sulla lingua originale solo se la voce in italiano non esiste, segnalandolo.
